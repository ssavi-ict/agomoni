# Audio Assets Directory

Place legal, non-copyrighted, or licensed audio files here:

- `mahalaya.mp3` — Gentle morning radio / Mahishasuramardini intro
- `dhak.mp3` — Traditional festive Dhak drum beat
- `conch.mp3` — Sacred Shankha blowing sound
- `dhak-reveal.mp3` — Celebratory Bodhan Dhak roll & temple gong

If any audio file is missing, the game's built-in `AudioManager` automatically falls back to procedural Web Audio synthesis without crashing or erroring.
