# Agomoni — Bringing Maa Durga Home

## Project Overview
- **Name:** Agomoni — Bringing Maa Durga Home (আগমনী — মাকে ঘরে আনা)
- **Purpose:** A story-driven, interactive web experience celebrating Durga Puja / Agomoni, where the player gradually brings Maa Durga closer to home.
- **Target Experience:** Festive, nostalgic, peaceful, magical, Bengali, emotional. Playtime ~3–5 minutes.
- **Deployment Platform:** Static website hosted on GitHub Pages.
- **Core Progression:** 6 sequential stages:
  1. Mahalaya (মহালয়া)
  2. Shukla Pratipad (শুক্লা প্রতিপদ)
  3. Shukla Dwitiya (শুক্লা দ্বিতীয়া)
  4. Shukla Tritiya (শুক্লা তৃতীয়া)
  5. Shukla Chaturthi (Start the Puja)
  6. Panchami / Bodhan (পঞ্চমী / বোধন)
- **Key Constraints:** Pure static client (no backend), completion-based progress (no calendar locks), localStorage persistence, centralized resilient audio, visitor counter abstraction ready for future Firebase.
